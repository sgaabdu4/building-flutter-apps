# Revisions

Load when the human gives feedback on a draft.

- Apply exactly the named changes. "Everything else is fine" freezes script lines, takes, timings, captions + designs.
- Voice feedback → change one thing, sample, verdict, then roll out.
- Graphic feedback → rebuild from the brand's approved source, not a new invention.
- One complaint → change only the named lines, never a whole-script rewrite.
- Re-run [review](render.md#review) for every scene whose timing or pixels changed.
